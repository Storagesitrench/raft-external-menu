## 🧩 About

**Raft External Menu** is a curated list of Raft open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, waypoint markers
- **Quality-of-Life Helpers** — inventory organizer, crafting notes, build planner
- **Research Notes** — island layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Resource Tracker — monitor collected materials
- Waypoint Markers — mark islands and points of interest
- Build Planner — outline structure layouts
- Sail Notes — log drift and wind patterns

### Wallhack
- Inventory Organizer — sort and group items
- Crafting Notes — reference recipe lists
- Storage Labels — label and categorize chests

### Aimbot
- Island Map Notes — record visited locations
- Depth Gauge — track underwater dive notes
- Aquarium Log — organize caught fish records
